Web Keuangan Koperasi

Website pengelolaan keuangan koperasi yang dikembangkan untuk mendukung penyajian informasi keuangan yang transparan, informatif, dan mudah diakses.

Tentang Proyek

Proyek ini merupakan proyek akademik yang dikerjakan secara tim untuk mengembangkan website pengelolaan keuangan koperasi berbasis data aktual.

Teknologi yang Digunakan

HTML CSS PHP Bootstrap

Dokumentasi

Peran Saya

Berperan dalam perancangan UI dan pengembangan front-end website koperasi, serta melakukan input dan pengelolaan data pada database MySQL untuk mendukung kebutuhan sistem.
