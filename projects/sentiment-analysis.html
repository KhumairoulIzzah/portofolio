Project Overview

This academic project focused on analyzing Google Maps reviews of Gus Dur's Tomb in Jombang, Indonesia. The workflow involved text preprocessing, TF-IDF feature extraction, handling class imbalance using SMOTE, and sentiment classification with Multinomial Naive Bayes.
