A search system that helps users find medicines based on symptoms by comparing their query with medicine-use descriptions.

Project Overview

The system processes symptom queries and medicine-use descriptions, then ranks relevant medicines using N-Gram representations and Cosine Similarity. The interface was built with Streamlit to present search results in a clear, accessible format.
